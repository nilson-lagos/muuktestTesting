# testing-muuktest-rewritten

Clean Playwright rewrite for the MuukTest staging flows that were originally generated by Muuk.

## What changed

This rewrite removes the generated wrappers, inline reporting code, hardcoded credentials inside specs, and overly long test files. The project now uses:

- Page Object Model
- reusable login fixture
- environment-based configuration
- shorter business-oriented tests
- clearer file names and responsibilities

## Important note

I rewrote the project from the functional intent visible in the generated files and the locators that were exposed in the page detail classes. Because the original recorder code did not preserve every semantic selector cleanly, a few locators may still need adjustment against the live staging UI.

The biggest areas to verify first are:

- tag edit modal controls
- bulk edit base URL controls
- row action menu buttons
- exact schedule and tag filter widget behavior
